# 🎂 Birthday Surprise — Piggy

Cute + funny + emotional birthday website starter.

## Test locally
Open `index.html` in a browser.

## GitHub Pages
Go to **Settings → Pages → Deploy from a branch**, choose `main` and `/ (root)`, then save.

## Customize later
- Replace `assets/photo1.svg` through `photo5.svg` with your photos and update the image filenames in `index.html`.
- Edit the birthday message in `script.js`.
- Edit names, captions and headings in `index.html`.

No backend or database is required.
